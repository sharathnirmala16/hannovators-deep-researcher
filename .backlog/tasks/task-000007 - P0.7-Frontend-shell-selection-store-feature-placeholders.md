## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented. domains/workspace/api: contract.ts (WorkspaceClient interface + WorkspaceApiError), httpClient.ts (fetch + zod decode of every response, ApiError normalization, EventSource with 'trace'/'end' events), fixtureClient.ts, workspaceClient.ts (VITE_USE_FIXTURES=1 switch), env.d.ts. domains/workspace/model: WorkspaceProvider (?workspace=<id> or the client default; load = idle|loading|ready|error; reload keeps the current data visible), useWorkspaceEvents SSE stub (appends, ignores repeated IDs; F1 replaces it with the full reducer). domains/evidence: tagged-union selection (none|source|claim|highlight), claim -> first highlight -> source + page, EvidenceSelectionProvider scoped to the open workspace (resets on workspace change without remounting panes). Features: index.ts + ui/<Entry>.tsx placeholder per feature; EvidenceTable takes view = evidence_profile_table|claim_matrix|synthesis_panel. app/: App -> WorkspaceProvider -> WorkbenchLayout (EvidenceSelectionProvider + 3 resizable panes run|evidence|source); uiComponentRegistry is a Record<UiComponentId, {pane, render}>, and PaneEntries mounts entries in ui_components order.
Fixture loading: fixtureClient uses import.meta.glob('/src/test/fixtures/*.json') as the dedicated API-boundary loader (frontend-code-structure skill, section 2 rule 5). Dependency Cruiser does not see glob imports, so no feature can reach the fixtures. With VITE_USE_FIXTURES=1 the four fixtures are separate lazy chunks; without it, Vite drops them from the bundle (verified with both builds).
VITE_USE_FIXTURES is read by Vite from frontend/.env* or the shell (vite.config.ts loads only the ports from the root .env). Run: VITE_USE_FIXTURES=1 pnpm dev. .env.example and README are outside this lane and are not updated.
Verification: a temporary jsdom render of App in fixture mode (deleted after the run) showed the medical fixture by default and the general one via ?workspace=, the registry mounted only the ui_components entries (GRADE profile vs claim matrix), the SSE stub ended, and there were no console errors. A temporary hook test confirmed claim -> highlight -> page and the reset on scope change. VITE_USE_FIXTURES=1 pnpm dev serves on 5176 and serves the fixture modules. pnpm check, pnpm build, pnpm test (3 passed), uv run pytest (4 passed).
