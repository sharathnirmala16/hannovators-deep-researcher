## Implementation Plan

All objects use z.strictObject (ContractModel extra=forbid). Fields with Pydantic defaults use .default() so input may omit them and the output type always has them. Export the enums, the schemas, and the inferred types. Datetimes accept ISO 8601 with or without an offset.

4. schema.test.ts: the schema accepts every fixture; it rejects an unknown TraceEventKind. No other tests.
5. Run pnpm check, pnpm build, pnpm test from frontend/ and uv run pytest from the root.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented schema.ts (zod mirror of models/contracts.py + events.py; strict objects, Pydantic defaults as .default(), Field bounds, hit-window and exactly-one-seed refinements, ApiError UPPER_SNAKE pattern). Enums live in a sibling api/enums.ts (mirror of enums.py, all 24 enums) re-exported by schema.ts, because schema.ts alone exceeded the 300-line ESLint max-lines budget. Import contracts through schema.ts only.
Fixtures (hand-written via a throwaway generator, not committed): workspace.medical.json = COMPLETED MEDICAL run on SGLT2 inhibitors in HFrEF, 40 sources (2 SEED, 2 RAW, 21 SCREEN_DISCOUNTED, 2 ACQUIRE_FAILED, 7 APPRAISE_DISCOUNTED, 6 APPRAISE_PROMOTED with RoB 2), 6 queries with refinement notes, 14 claims (METRIC arms, CLAIM, RECOMMENDATION) with quotes, 13 highlights, synthesis with 3 GRADE rows. workspace.general.json = COMPLETED GENERAL run (domain_mode AUTO) on sodium-ion vs LFP cost parity, 40 sources, 12 claims across all verdicts, 11 highlights (web highlights have pdf_url null and no rects). graph.*.json: one node per source, 53 and 46 CITES/RELATED/SEED_MATCH edges. The 6 promoted medical trials are real landmark trials (DOIs as external_id); every other literature record uses Crossref test DOIs (10.5555/hdr-fixture.*), and web URLs use example.com/org/net hosts. I1 regenerates the fixtures from real runs.
Cross-check: both workspace fixtures validate with WorkspaceState.model_validate_json and both graphs with GraphView (uv run python, read only); all claim/highlight/source/graph IDs resolve.
Contract question for A7 (not a model bug, PLAN.md does not define it): the fixtures use cumulative PRISMA funnel counts (raw = all non-seed candidates found; screen_promoted = all that passed screening, including later ACQUIRE_FAILED/APPRAISE_*), not current-status counts. A7 workspace_state.py should confirm or the fixtures change.
Checks: pnpm check, pnpm build, pnpm test (3 passed), uv run pytest (4 passed). knip prints a non-failing hint to remove zod from knip.json ignoreDependencies; knip.json is outside this lane, so it is left for the integrator.
