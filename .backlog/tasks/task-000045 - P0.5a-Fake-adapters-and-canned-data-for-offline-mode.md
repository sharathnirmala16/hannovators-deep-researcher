## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. adapters/fake/text.py: shared tokenizer (lowercase word tokens, PubMed [tag] and boolean words dropped, small stopword set, crude plural strip).
2. adapters/fake/catalog.py: load data/medical.json and data/general.json (research_question, records: CandidateRecord[], links: SourceLinkRecord[]) once, validated by a fake-internal Pydantic model; overlap scoring; pick the best-matching set per query so medical and general results never mix; exact PMID/PMCID/DOI/URL lookup.
3. chat.py FakeChatModel: getattr(schema, 'fake_example'); missing -> FakeExampleMissingError naming the schema; result passed through schema.model_validate.
4. decisions.py FakeDecisionModel: blake2b of (question key, state[, option]) -> choice (argmax of peaked weights over the given options), score (expected level index plus level probabilities), noul (float, true/false probabilities). Confidence for choice and score only.
5. embeddings.py FakeEmbedder: signed hashed bag-of-words, EMBEDDING_DIMENSIONS long (constructor arg, default from contracts), L2-normalized; empty text -> fixed unit basis vector; instruction ignored so query and document vectors compare.
6. web.py FakeWebSearch: WEB records as SearchResults (score = overlap), include/exclude domains, limit; fetch() returns markdown for known URLs (max_chars), ProviderFailure NOT_FOUND otherwise.
7. literature.py FakeLiteratureSearch: count/search over PUBMED+EUROPEPMC records, related() from canned links, open_access_pdf_url from pdf_url or pmcid -> https://fake-oa.invalid/pdf/<id>.pdf; fake_pdf_bytes() and fake_http_transport() (httpx.MockTransport) serve the bundled PDF for those URLs.
8. data/: about 40 medical records (SGLT2 inhibitors vs placebo in HFrEF: RCTs, cohorts, reviews, editorial, animal studies, case report, off-topic, cross-source duplicates, web pages) and about 40 general records (due diligence on a fictional sodium-ion battery maker's claims). Synthetic IDs (PMID 991xxxxx, DOI 10.5555/*, .example hosts). One text-layer trial PDF under 50 KB made once with PyMuPDF.
9. Protocol conformance via TYPE_CHECKING assignments in each module (checked by strict mypy).
10. Tests in tests/unit/adapters/fake/: missing fake_example error; decision determinism and choice validity; embedder similarity order and unit norm.
11. Run ruff format/check, mypy, pytest, uv build; commit; rebase on origin/main; push; PR.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented adapters/fake/: text.py (shared tokenizer), catalog.py (loads and validates data/*.json, overlap scoring, best-matching domain set answers, exact PMID/PMCID/DOI/URL lookup), chat.py, decisions.py, embeddings.py, web.py, literature.py. Protocol conformance is checked by strict mypy through TYPE_CHECKING assignments in each module.

Data: medical.json has 41 records (32 PUBMED, 4 EUROPEPMC, 5 WEB) for SGLT2 inhibitors vs placebo in HFrEF: direct RCTs, an underpowered pilot RCT, HFpEF/acute-HF/surrogate-outcome RCTs (indirect), cohorts, SR/MA and network MA, a narrative review, an editorial, a letter, a protocol, a case report, a cost-effectiveness study, two animal studies, off-topic trials, Europe PMC duplicates of PubMed records (same PMID/DOI, different external_id and title casing), a journal-page WEB duplicate, a guideline, a label, news, and a patient forum post. 22 CITES/RELATED links. general.json has 40 records (36 WEB, 4 EUROPEPMC) for due diligence on the fictional Kestrel Ionics 175 Wh/kg claim and 2027 gigafactory: company claims, an independent lab measuring 162 Wh/kg, a short-seller report, filings, delays, a lawsuit and rebuttal, name-collision off-topic pages, syndicated and tracking-param/www/fragment URL duplicates. 9 links. All identifiers are synthetic (PMID 991xxxxx, DOI prefix 10.5555, .example hosts). fake_trial.pdf is a 2-page, 8.9 KB text-layer PDF of the CARDINAL-HF record (generated once with PyMuPDF); page.search_for finds its result sentences and table rows.

Fake behavior chosen: FakeDecisionModel score = expected level index (0..n-1) with probabilities keyed by level text, confidence = max probability; choice = most probable given option; noul has true/false probabilities and no confidence. FakeEmbedder ignores the instruction and maps token-free text to the first basis vector. FakeWebSearch.fetch raises ProviderFailure NOT_FOUND for URLs outside the catalog. FakeLiteratureSearch.count = number of matching records; open_access_pdf_url returns pdf_url, else https://fake-oa.invalid/pdf/<PMCID>.pdf. fake_http_transport() (httpx.MockTransport) serves fake_pdf_bytes() for those URLs and 404 for the rest.

Notes for the integrator (no workarounds made):
1. infrastructure/http.py create_http_client() has no transport parameter. For offline OA downloads, P0.5 or A5 must let the composition root pass fake_http_transport() (or an injected client) to the downloader.
2. The LiteratureSearch port has no fetch-by-ID method. The fake accepts a PMID, PMCID, or DOI as the search query (as PubMed esearch does); S1 and A4 should agree on that, or a port method should be added.
3. The DecisionAnswer score scale and probability keys for score questions are a fake assumption; A2 must confirm the Jev wire shape.
4. There is one bundled PDF, so general-domain OA records also resolve to the medical trial PDF.

Validation: ruff format --check, ruff check, mypy (52 files, strict), pytest (9 passed), uv build (wheel contains data/*.json and fake_trial.pdf), all rerun after rebase on origin/main (no new upstream commits). Smoke script: both JSON sets validate; a PubMed-syntax HFrEF query matches 36 medical literature records and no general ones; the general query returns 36 WEB results; PMID 99100001 returns the PubMed record and its Europe PMC duplicate; the OA URL is served as application/pdf through fake_http_transport(); unknown URLs give 404 or NOT_FOUND. Fake Jev score spread over 81 titles: 0.43 to 3.87 (sd 0.83), noul > 0.5 for 44/81. PR: https://github.com/sharathnirmala16/hannovators-deep-researcher/pull/4
