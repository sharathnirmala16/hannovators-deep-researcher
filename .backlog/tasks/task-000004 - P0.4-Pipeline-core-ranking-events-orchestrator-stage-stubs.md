## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- ranking.py: reciprocal_rank_fusion(rankings, k=60) returns (item, score) best first; ties keep first-appearance order (stable sort); duplicates inside one list count once. z_scores uses population std; zero variance or one item -> 0.0; empty -> [].
- events.py: DatabaseEventSink(repositories) -> Repositories.append_event.
- context.py: PipelineServices (app_settings, session_factory, repositories, chat, embedder, decisions, web, literature, events) and StageContext(PipelineServices) adding workspace_id, settings (WorkspaceSettings), stage, and emit(kind, message, payload). Additions beyond the PLAN 5.1 field list: app_settings (S3 needs RUN_BUDGET_MAX_CANDIDATES), stage + emit (so stages emit without repeating IDs). No models/ contract changed.
- orchestrator.py: STAGE_ORDER = StageId order. begin_run does one conditional UPDATE ... RETURNING (CREATED/AWAITING_REVIEW -> RUNNING), raises RunStateError otherwise (A7 maps it to 409 before spawning the task) and LookupError for unknown IDs; start stage derives from current_stage. run_from emits STAGE_STARTED/STAGE_COMPLETED around every stage, pauses at AWAITING_REVIEW after decompose unless auto_continue, and emits a STATUS event {status} after each status write (RUNNING, AWAITING_REVIEW, COMPLETED, FAILED). Exception -> FAILED, error='<stage>: <Type>: <msg>', STAGE_FAILED {error}, STATUS FAILED. Cancellation also marks FAILED ('run cancelled') and re-raises, so a run is never left RUNNING. Orchestrator(services, stages) overrides individual runners.
- Stubs: services/pipeline/stages/<stage_id>/__init__.py for all 9 StageIds emit PROGRESS '<stage>: not implemented'; STAGE_STARTED/COMPLETED come from the orchestrator (AC #3 interpretation, so stage lanes never duplicate them).
- Tests: tests/unit/services/test_ranking.py (z zero variance, z one item, RRF empty lists, RRF ties); tests/integration/services/pipeline/test_orchestrator.py on real SQLite (checkpoint + resume in section 3 order with STARTED/COMPLETED for every stub, auto_continue runs through; stage exception -> FAILED + STAGE_FAILED, earlier events kept). Also checked by hand with a throwaway script (not committed): begin_run while RUNNING / after COMPLETED -> RunStateError, unknown ID -> LookupError, cancel -> FAILED.
- Verification: ruff format --check, ruff check, mypy (62 files), pytest (11 passed), uv build all pass.

PR: https://github.com/sharathnirmala16/hannovators-deep-researcher/pull/5. DoD #1 (checks pass on main after merge) left unchecked until the PR merges.
